# Bluefist dashboard

The Next.js dashboard is part of the Bluefist prototype. Start the FastAPI service from the repository root, then run `npm ci` and `npm run dev` from this folder. Open [http://localhost:3000](http://localhost:3000). See the root README for configuration, API, security limits, and the full proposal workflow.

Set `NEXT_PUBLIC_API_BASE` before starting/building the frontend when the API is not at `http://127.0.0.1:8000`. The dashboard token field is for a secured API and is cleared when the page reloads.
